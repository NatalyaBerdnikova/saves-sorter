# Saves Sorter

Приложение для iPhone: сохранённые посты разбираются по схеме **страна → город → «Что посетить» / «Что купить»**. Сервера нет, всё лежит на устройстве.

Рабочее имя — Saves Sorter. В названии и на иконке нет чужого логотипа.

## Что нужно

- Mac с Xcode 15 или новее (цель — iOS 17).
- iPhone. В симуляторе само приложение открывается, но лист «Поделиться» из Instagram проверяется только на устройстве.
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.

Проект в репозитории описан в `project.yml`. Файл `.xcodeproj` сюда не положен: эта среда Linux и XcodeGen здесь не запускается. На Mac он собирается одной командой.

## Сборка

```bash
cd /путь/к/репозиторию
# при желании поменяйте префикс и команду подписи
open -e Config/Shared.xcconfig
brew install xcodegen
xcodegen generate
open SavesSorter.xcodeproj
```

В `Config/Shared.xcconfig` одна строка задаёт идентификаторы:

```
BUNDLE_ID_PREFIX = com.example.savessorter
APP_GROUP_ID = group.$(BUNDLE_ID_PREFIX)
DEVELOPMENT_TEAM =
```

Поставьте свой префикс, например `com.natalya.savessorter`, и Team ID (10 символов из Apple Developer). После правки xcconfig достаточно пересобрать проект. `xcodegen generate` нужен заново, только если менялся `project.yml`.

## Что включить в Xcode

Оба таргета: **SavesSorter** и **ShareExtension**.

1. Signing & Capabilities → Team. Один и тот же у приложения и у расширения. Стиль подписи — Automatic.
2. Capability **App Groups** у обоих. Идентификатор группы: `group.` + ваш `BUNDLE_ID_PREFIX`, например `group.com.natalya.savessorter`.
   В репозитории группа записана как `$(APP_GROUP_ID)`. Xcode подставляет её при подписи. Если подпись ругается на буквальное `$(APP_GROUP_ID)`, добавьте группу руками в Capabilities обоих таргетов — строка должна совпасть.
3. В портале разработчика должны существовать App ID приложения, App ID расширения (`…share`) и сама App Group. Automatic signing обычно создаёт их сам.
4. Схема **SavesSorter**, устройство — ваш iPhone, Run.
5. Язык интерфейса берётся из языка iPhone. Русские строки в `Localization/ru.lproj`, английские — в `Localization/en.lproj`. Чтобы принудительно открыть русский при английской системе: Edit Scheme → Run → Options → App Language → Russian.

Проверка: Настройки → внизу блок «Подпись». Там видны bundle id и группа. Если написано, что App Group не найден, расширение не увидит записи.

## Как пользоваться

1. В Instagram откройте пост или рилс → **Поделиться**.
2. Выберите **Saves Sorter**. Если пункта нет: «Ещё» / More и включите приложение.
3. Расширение сразу пишет ссылку (статус «ожидает») и пытается забрать подпись. Если сеть не успела, приложение доделает это при запуске и при возврате на экран.
4. Коллекция: страна → город → переключатель **«Что посетить»** / **«Что купить»**.
5. Вкладка **«Проверить»** — неуверенный разбор и всё, у чего не нашлись страна и город. Покупка без города туда же и в строку **«Без города»**.
6. Вкладка **«Не разобрано»** всегда на панели, со счётчиком. Туда попадают битая ссылка, удалённый пост, пустая подпись и подпись, в которой нет конкретных мест (например, «смотрите в видео»). У строки есть ссылка, причина, «Повторить» и «Разобрать вручную».

На городе: скопировать названия текущего списка и выгрузить CSV для Google My Maps (колонки `Name,Address,City,Country,Note,Instagram link`). Адрес места — «название, город, страна». Для покупок в название карты попадает магазин, если он есть. На стране — CSV всех мест «посетить». В настройках — JSON-копия всей коллекции и CSV обоих списков целиком.

Поиск — лупа на вкладке «Коллекция».

ИИ выключен. В Настройках можно вставить свой ключ OpenAI или Anthropic. Ключ остаётся в Связке ключей и уходит только этому провайдеру вместе с текстом подписи.

## Тесты

В Xcode: схема SavesSorter, ⌘U. Тесты разбирают подпись, ссылки, правила и CSV. Они не запускают приложение-хост.

На Mac с установленным Swift можно так же:

```bash
swift test
```

`Package.swift` в корне нужен только для этих тестов. Приложение собирается из `SavesSorter.xcodeproj`, не из пакета.

## Ограничения

- Нет метки локации и нет текста из самого видео. Берётся подпись страницы `instagram.com/p/…` или `/reel/…`, запасной вариант — `/embed/captioned/`.
- Запрос идёт с User-Agent как у Shortcuts, не как у браузера Chrome: с браузерным агентом страница часто приходит пустой.
- Ссылка на обложку быстро протухает. Если картинка скачалась, байты лежат в группе приложений.
- Правила (русский, английский и немного турецкого) ошибаются. Сомнение уходит в «Проверить», а не в город.
- Один пост может дать несколько мест. Покупка и место из одной подписи раскладываются отдельно, если в тексте есть и то и другое.
- Сайт может не отдать страницу. Запись останется в «Не разобрано», её можно повторить.
- Справочник стран и городов — `SharedCore/Resources/GeoData.json`. Его пересобирает `python3 Scripts/generate_geodata.py`.

## Как устроено

- Общая логика без UI: `SharedCore` (разбор HTML, ссылки, классификатор, экспорт).
- Хранилище — JSON в контейнере App Group, запись через `NSFileCoordinator`, чтобы приложение и расширение не затирали друг друга. SwiftData здесь не используется: с расширением общий контейнер SwiftData чаще ломается.
- Расширение только принимает `p`, `reel`, `reels`, `tv` и выкидывает хвост вроде `?igsh=`.
- Обложка, если скачалась, лежит рядом с JSON.

## Что не проверялось компилятором Xcode

Логика разбора и правил прогнана командой `swift test` (30 тестов). Сам таргет SwiftUI и расширение на этой машине не собирались: здесь нет Xcode и iOS SDK. Имеет смысл первым делом открыть проект на Mac и собрать оба таргета. Если что-то не соберётся, вероятные места:

- подстановка `$(APP_GROUP_ID)` в entitlements;
- класс расширения `ShareViewController` в `NSExtensionPrincipalClass`;
- флаг `APPLICATION_EXTENSION_API_ONLY` у расширения;
- модульные тесты без host-приложения (⌘U).
